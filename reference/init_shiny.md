# Initialize Shiny Project using this function

Initialize Shiny Project using this function

## Usage

``` r
init_shiny(path = getwd(), confirm = TRUE)
```

## Arguments

- path:

  Path where shiny project template is created

- confirm:

  Logical. If TRUE, prompts user for confirmation before creating
  template.

## Value

Return shiny project file and directory template in current working
directory.

## Examples

``` r
if (FALSE) { # \dontrun{
init_shiny()
} # }
```
